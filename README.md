# Problema Das Oito Rainhas
## Comparação entre 3 algoritmos.

### Algoritmos
- Força Bruta (bruteforce.py)
- Backtracking (backtracking.py)
- Genético (genetic.py)

### Objetivo

Comparar o desempenho dos algoritmos considerando:
- Tempo de execução
- Quantidade de configurações avaliadas
- Capacidade de encontrar soluções válidas
- Taxa de sucesso

### Tecnologias

- Python
- Pandas
- Matplotlib
- Pytest
